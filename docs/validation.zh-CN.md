这是将教师结构送入同一评价器的阳性检查，**不是 ROOT 生成结果**。

| 教师 | PoseB/化学结构验收 | 原子恢复 | XYZ 支持的键恢复 | 统一编码 pIC50 | MMFF94s 应变 kcal/mol | PLIP 恢复 |
|---|---|---:|---:|---:|---:|---:|
| 6pyy_015 | 通过 | 1 | 1 | 5.816805 | 11.489390 | 9/9 |
| 3w54_003 | 通过 | 1 | 2/3 | 8.711567 | 18.127674 | 10/10 |

这揭示两个解释限制：

1. 统一芳香/Kekulé 编码后的 6pyy 教师 pIC50 与存档值 6.535594 不同。候选必须减去统一处理的教师重评分；不得把存档值直接用作同条件基准。
2. 3w54 教师有一条已选键未得到当前独立 XYZ 键级重建支持。XYZ 键级感知不是无误的真值判定器；保守恢复指标会低估某些有效结构。代码不偷偷用教师键补正重建结果，保留每条键的预期/原始/重建语义及距离。正式实验解释前需要进一步定标这一审计规则。

## ROOT 与 Agent 接口

先执行两位教师各一条 100 步固定条件轨迹，末端使用未投影原始预测。两条都因价态不合法记录为 chemical_invalid，没有补采样。这个样本量不支持对 ROOT 能力下结论。

随后使用 `configs/interface.yaml` 完成真实两轮反馈验证，采用冻结 ROOT 与实际 DeepSeek API。每位教师 17 次尝试，两位共 **34 次**：10 个初始基线、16 个搜索候选、8 个独立确认候选。合计 18 个化学可解码候选和 16 个化学无效候选，所有尝试均保留。

| 教师 | 发现阶段优胜 J | 独立确认优胜路径合格数 | 确认优胜 J | 确认基线 J |
|---|---:|---:|---:|---:|
| 6pyy_015 | 0.8889 | 1/2 | 0.4444 | 0 |
| 3w54_003 | 0.4167 | 0/2 | 0 | 0 |

6pyy 优胜来自第 2 轮；3w54 优胜来自第 1 轮，验证了跨轮选择。3w54 的独立确认没有结构合格候选。发现样本与确认样本都很少，这些结果不能支持动态路径优越性的统计结论。

实际发生 4 次整轮规划，另有 1 次 JSON/提案修订，共保存 5 份 API 行动响应。修订没有增加轮次或候选。完整结束后原配置再次启动，核对 73 个生成记录、原始输出及 API 响应文件：内容哈希和修改时间均不变，没有新增生成或 API 请求。
